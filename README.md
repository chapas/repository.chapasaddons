# repository.chapasaddons

Kodi addon repository by chapas.

## Install

1. Download `repository.chapasaddons-1.0.0.zip` from [zips/repository.chapasaddons](zips/repository.chapasaddons/).
2. In Kodi, go to Settings > Add-ons > Install from zip file and select the downloaded file.
3. Go to Install from repository > chapas Addons Repository and install the addons you want.
